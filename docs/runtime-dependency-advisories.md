# Runtime dependency advisory review

Reviewed on 2026-11-17 for open-source readiness ticket 02. Owner: Tally maintainers.
Next review: 2026-12-01, before a release, or when the features below change, whichever comes first.

## Audit method and result

Used pnpm 10.34.4 and the native registry audit against `pnpm-lock.yaml`:

```sh
pnpm audit --json
pnpm audit --prod --json
pnpm install --frozen-lockfile
```

| Audit                                | Low | Moderate | High | Critical |
| ------------------------------------ | --: | -------: | ---: | -------: |
| Original full lockfile               |  11 |       35 |   32 |        3 |
| Updated full lockfile                |   7 |       21 |   17 |        2 |
| Updated production dependency filter |   0 |        0 |    0 |        0 |

Counts describe reported advisories, not proven exploits. The production filter is
insufficient: SvelteKit and Svelte are declared in `devDependencies` but generate
runtime worker and browser code. The full graph and application imports were reviewed.
No audit suppressions, forced remediation, dependency overrides, new direct packages,
or install-script permissions were added.

## Validation

With the disabled-analytics values from `.env.example` exported for check/build:

```sh
export PUBLIC_POSTHOG_ENABLED=false
export PUBLIC_POSTHOG_PROJECT_TOKEN=phc_your_project_token_here
export PUBLIC_POSTHOG_HOST=https://eu.i.posthog.com
pnpm check
pnpm build
```

- Frozen-lockfile installation passed without enabling ignored lifecycle scripts.
- Svelte/type check: zero errors and warnings.
- Focused PostHog proxy tests: 3 passed.
- Full unit/integration suite: 83 tests across 4 files passed.
- Production build and worker smoke checks passed.
- Chromium browser suite: all 6 tests passed, including room hydration, joining,
  voting, reveal, reload and moderation. No independent browser failure reproduced.
- Formatting and lint passed (`pnpm exec oxfmt package.json docs/runtime-dependency-advisories.md`, then `pnpm lint`).

Live PostHog ingestion was not tested; checks used disabled analytics and the existing
proxy tests. This review does not claim that an audit detects every vulnerability.
