# Domain-Optionen für Tally

Stand: 2026-07-08. Verfügbarkeit per RDAP und DNS (NXDOMAIN) geprüft.
Verbindlich ist erst der Check im Registrar-Warenkorb.

## Namensbedeutung

"Tally" = Strichliste, Zählstand ("tally up the votes"). Historisch das
Kerbholz (tally stick). Passt zum Auszählen der Stimmen pro Planning-Poker-Runde.

## Wenn es unbedingt .com sein soll

1. **Freie Variante registrieren** (ca. 10 EUR/Jahr): `tallyscrum.com` und die
   anderen freien .com-Kandidaten oben. Günstig und sofort verfügbar.
2. **Zweitmarkt**: `tallyroom.com` steht zum Verkauf (ca. 3.000-9.000 USD,
   HugeDomains). `votetally.com` liegt auf dem Afternic-Marktplatz (Preis auf
   Anfrage). `gettally.com` gehört einem Unternehmen (MarkMonitor,
   Markenschutz) - aussichtslos.
3. **Broker/Direktanfrage**: Für privat gehaltene Domains wie `tallypoker.com`
   (GoDaddy Domain Broker, Sedo). Gebühr plus 10-20 % Provision, Erfolg ungewiss.
4. **Backorder/Drop-Catching**: DropCatch/SnapNames (~60-80 USD), nur sinnvoll
   wenn eine Domain tatsächlich ausläuft. Sehr geringe Erfolgschance.

## Empfehlung

**`tallypoker.app`** registrieren (Favorit insgesamt) oder **`tallyscrum.com`**,
falls .com Pflicht ist. Beides unter 15 EUR/Jahr, Keyword in der Domain,
saubere TLD. Teure Zweitmarkt-Domains lohnen sich erst, wenn das Produkt
Traktion hat.

.app erzwingt HTTPS (HSTS-preloaded TLD) - mit Cloudflare ohnehin Standard.
.xyz ist SEO-neutral (Google behandelt gTLDs gleich), hat aber bei Nutzern und
Spamfiltern einen schlechteren Ruf.
